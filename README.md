## À propos

Mon portfolio personnel, construit en Next.js 15 (App Router) avec TypeScript strict. Bilingue français/anglais, thème clair/sombre, et une identité visuelle "developer aesthetic" avec accent lime-green, inspirée de l'esthétique éditeur de code.

## Fonctionnalités

- 🌐 **Internationalisation complète** (FR/EN) via `next-intl`, routing localisé
- 🌓 **Thème clair/sombre** avec `next-themes`, transitions fluides
- 🎬 **Animations** riches via Framer Motion : reveal au scroll, typewriter, transitions de page
- 🧩 **Design system** basé sur shadcn/ui, avec composants sur mesure (project cards, timeline interactive, hero animé)
- 📦 **Section projets dynamique** générée depuis une source de données centralisée, avec filtrage par mise en avant (featured)
- 🐳 Build et déploiement conteneurisés (Docker multi-stage)

## Stack technique

| Couche | Technologie |
|---|---|
| Framework | Next.js 15 (App Router) |
| Langage | TypeScript (strict) |
| Style | Tailwind CSS v4, shadcn/ui |
| Animations | Framer Motion |
| i18n | next-intl (FR/EN) |
| Thème | next-themes |
| Infrastructure | Docker (build multi-stage) |
